# Support

## Before asking for help

1. Check the current [README](README.md), especially installation and
   troubleshooting.
2. Search existing [Cognivoy issues](https://github.com/chenchunrun/Cognivoy/issues).
3. Reproduce the problem on the latest supported release when possible.

## Where to ask

- Use GitHub Discussions for setup questions, usage help, and general ideas.
- Open a GitHub issue for a reproducible defect or a scoped feature proposal.
- Follow [SECURITY.md](SECURITY.md) for vulnerabilities or reports containing
  sensitive information.

When reporting a problem, include the Cognivoy version or commit, operating
system, Python and Node versions, installation method, relevant configuration
with secrets removed, exact reproduction steps, expected behavior, and sanitized
logs. Support is community-provided on a best-effort basis; no response-time or
availability guarantee is offered.
