# Upstream Attribution and Contribution Policy

Cognivoy is an independently maintained derivative of
[HKUDS/DeepTutor](https://github.com/HKUDS/DeepTutor), licensed under Apache-2.0.
Its inherited compatibility baseline is DeepTutor v1.5.11. The application,
package names, frontend, runtime settings and agent workflows have subsequently
been modified. See `NOTICE`, `MODIFICATIONS.md`, and `THIRD_PARTY_NOTICES.md`.

This public repository starts from a reviewed source snapshot. It does not
include the maintainer's private development history or planning records.
This does not remove or transfer any upstream copyright or license obligations.

Upstream fixes are reviewed individually and adapted to Cognivoy's interfaces.
Direct merges of upstream release branches are not supported. Contributions
that port upstream code must identify its source and preserve applicable
copyright, license and modification notices. Security fixes require regression
tests, and user-facing changes must preserve authorization and data isolation.

Use this repository's issues for Cognivoy support. Upstream maintainers are not
responsible for this independent distribution.
